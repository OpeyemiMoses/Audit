DOCUMENTATION & SUPPORT

Help Center & Frequently Asked Questions

What is the purpose of AUDIT for Binance Agent OS?
AUDIT is a security infrastructure layer. It prevents autonomous crypto agents from executing dangerous actions on Binance or BNB Chain by providing standardized pre-flight checks and Groq AI risk evaluations.
How does an agent receive an ALLOW or BLOCK decision?
The agent calls the evaluate_agent_decision tool via MCP. AUDIT aggregates on-chain bytecode, honeypot flags, and order book depth, feeding them to Groq's high-capacity model to generate an enforceable verdict.
What blockchains are supported out-of-the-box?
Primary support is optimized for BNB Smart Chain (BSC 56), opBNB (204), and BSC Testnet (97), with full multi-chain EVM coverage for Ethereum (1), Base (8453), Arbitrum (42161), and Polygon (137).
Can AUDIT run without an external database?
Yes. AUDIT utilizes high-efficiency in-memory caching with optional Redis connectivity, ensuring zero-configuration deployment for local and cloud environments.
